# Distraction-Free TTS Reader

🧠 **Overview**  
A lightweight, browser-based Text-to-Speech (TTS) reader designed for focus and accessibility. Paste any text, choose a voice, and listen — no logins, no tracking, no distractions.

🔒 **Privacy-First**  
Runs 100% in-browser. No data is sent to any server.

---

## ✨ Features

- 🔊 Reads text aloud using the Web Speech API  
- 🧘 Simple, clean, distraction-free interface  
- 🧠 Great for writers, readers, or users with ADHD/ND  
- 🚫 No backend, no user data collected  
- 🧠 Smart inactivity reminders to stay focused  
- ⚙️ Voice and speed selection  
- 📦 Now available as a Chrome Extension

---

## 🧩 Technologies Used

- HTML + CSS + JavaScript  
- Web Speech API (speechSynthesis)  
- Chrome Extension (Manifest V3)  

---

## 🧪 How to Use

### 🔗 As a Web App

1. Clone or download this repository  
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox)

### 🧩 As a Chrome Extension

1. Clone or download this repository  
2. Go to `chrome://extensions` in your browser  
3. Enable **Developer Mode** (top right)  
4. Click **Load Unpacked**  
5. Select this project folder  
6. Pin the extension and use it from your browser!
